# BGM

BGM は、合成音声と一緒に流すローカルの配信素材です。MP3 または FLAC を `show/bgm/` の直下に置いてください。取り込み処理も目録ファイルも要らず、中身は git 管理外です。

パネル・CLI・MCP から一覧を要求するたびに、制御サーバがディレクトリを読み直します。拡張子を含むファイル名がそのままトラック id になります。サブディレクトリやシンボリックリンクは辿りません。別の場所を使う場合は `--bgm <dir>` でライブラリごと移せます。

ネイティブシェルでは **Window → Open BGM Folder** から既定の置き場を開けます。

```sh
yarn ctl bgm list
yarn ctl bgm play opening.mp3 --volume 0.2 --loop on --fade-in 1 --fade-out 1
yarn ctl bgm fade 1 1
yarn ctl bgm pause
yarn ctl bgm resume
yarn ctl bgm stop
```

既定の音量は 0.2、ループはオン、フェードインとフェードアウトはそれぞれ 1 秒です。フェードは 0〜10 秒で、0 は瞬時の切り替えです。別のトラックを再生中に切り替えると、前のトラックをフェードアウトしながら新しいトラックをフェードインします。最初の再生、または停止中からの再生ではフェードインだけを使います。

フェードアウトは「去っていくトラック」が使う時間なので、`stop` もこれに従ってフェードアウトします。停止した瞬間に再生位置は 0 へ戻り、音だけが残って消えていきます。その尾が鳴っているあいだに再生が届いた場合は、去りかけのトラックを引き戻すのではなく、新しく頭から鳴らし直します。`stop` は選択を残すので、もう一度再生すると先頭から始まります。一時停止と再開は即時です。フェードを掛けると、フェードの途中から再開するとはどういうことかを定義する必要が生じるためです。尾を残さず切りたいときは、フェードアウトを 0 にするか、パネルの「取り外す」を使ってください。後者は選択ごと外し、何も鳴り残しません。

`yarn ctl bgm fade <inSeconds> <outSeconds>` で現在のフェード設定を変えられます。`bgm play` には `--fade-in` と `--fade-out` を付けられ、その再生と同時に設定も更新します。台詞中の BGM キューでトラックを切り替えるとき、停止中から再生するとき、そして停止するときは、その時点の設定を使います。一時停止からの再開は即時です。

## パネルと MCP

BGM タブでは、素材一覧、選択、再生、一時停止、停止、音量、ループ、フェードイン、フェードアウトを扱えます。「**エフェクト（BGM のみ）**」には、音色、コンプレッション、ステレオ幅、リバーブ、ピッチシフト、非線形プレゼンスがあります。変更は再生中にも反映され、合成音声の処理や、その声に選んだ `room` は変えません。

MCP では 8 つめの `bgm` ツールが同じ操作を受け持ちます。

| action | 入力 |
|---|---|
| `list` | なし。再走査し、MP3/FLAC の正確な id を返します。 |
| `play` | `track`。任意で `volume`・`loop`・`fade`・`dsp` も指定できます。 |
| `pause` / `resume` / `stop` | 他のフィールドはありません。 |
| `settings` | `volume`・`loop`・`fade`・`dsp` のうち 1 つ以上。 |

たとえば次の設定は、音量、フェード時間、コンプレッション、リバーブだけを変えます。

```json
{
  "action": "settings",
  "volume": 0.16,
  "fade": { "inSeconds": 1.25, "outSeconds": 0.75 },
  "dsp": {
    "toneDb": 1,
    "compression": 0.25,
    "reverb": { "mix": 0.08, "decay": 0.45 },
    "pitch": { "semitones": 7, "mix": 0.35 },
    "presence": { "amount": 0.25, "drive": 3, "frequencyHz": 3200 }
  }
}
```

`status` からは、選択中のトラック、再生状態、位置、長さ、音量、ループ、解決済みのフェード設定、解決済みの DSP 値を読めます。呼び出し側は `/bgm/` の URL を組み立てず、`list` が返した id を使ってください。

## 台詞の中の BGM キュー

BGM の再生操作は、台詞の中にも置けます。台詞の口の時計に合わせて、その位置で動作します。

```text
ここで導入を始めます。[@bgm play opening.mp3]
次の行で一時停止します。[@bgm pause]
この行で選択中のトラックを再開します。[@bgm play]
この区間の終わりで停止します。[@bgm stop]
```

`play` のトラック名は省略できます。省略時は選択中のトラックを再開します。一時停止からの再開は即時で、停止中からの再生はフェードインします。`play` の後ろは BGM ファイル名全体として扱うため、空白と日本語を含められます。`[` と `]` は予約文字です。これらのキューは通常の `speak`、`say`、`queue`、台本のテキストを通り、MCP や CLI に専用の操作を追加する必要はありません。トラック切り替え、停止中からの再生、そして停止は現在のフェード設定を使い、フェード時間自体は短いインライン構文には書きません。音楽で締めるセグメントは、フェードアウトを台本の setup で一度決めておいて、最終行の末尾に `[@bgm stop]` を置く形になります。

### 行の位置で構造化パッチを適用する

行の途中で BGM の設定を変える場合は `[@bgm set {JSON}]` を使います。JSON オブジェクトは BGM コマンドのパッチで、`action` は省略可能な `play`・`pause`・`stop`、`track` は省略可能なファイル名または `null`、`volume` は 0〜1、`loop` は真偽値、`fade.inSeconds` と `fade.outSeconds` は 0〜10、`dsp` は `toneDb`（−6〜6）、`compression`（0〜1）、`width`（0〜2）、`reverb.mix`（0〜0.5）、`reverb.decay`（0〜0.9）、`reverb.damping`（0〜1）、`pitch.semitones`（−24〜24）、`pitch.mix`（0〜1）、`presence.amount`（0〜1）、`presence.drive`（0〜8）、`presence.frequencyHz`（500〜8000）を受け取ります。ピッチの既定値は半音 0・ミックス 0 で、ミックス 0 なら元のピッチを保ちます。プレゼンスの既定値は量 0・ドライブ 2・周波数 3200 Hz で、量 0 なら倍音を加えません。ファイル名だけなら曲を先頭の停止状態で選び、`action` が `play` のときだけ再生します。`null` は曲を取り外し、どの `action` よりも優先されます。省略したフィールドは現在値を保ち、パッチの設定は行の後も残ります。

パッチはキューの位置で原子的に適用され、固定された libsonare のチェインを使います。プロセッサの追加や時間をかけた補間は行いません。どの階層でも未知のフィールドや空のパッチ、`cmd`、`id`、`revision`、`transport`、`position`、`at` などコマンドの外枠やサーバが付けるフィールドは拒否します。不正な JSON や範囲外の値を含む行も、キューへ積む前に拒否します。許可されるフィールドの表と複合例は[原稿と演出](lines-and-cues.md)にあります。

## BGM 専用エフェクト

固定チェーンは libsonare の音色調整、コンプレッサー、選んだ帯域の成分から非線形倍音を生成するプレゼンス、ステレオイメージャー、テンポを保つピッチシフター、プレートリバーブの順です。公開する値は、各プラグインの全パラメータより意図的に絞ってあります。

| 操作 | 範囲 | 無加工時／既定値 |
|---|---:|---:|
| 音色 | −6〜+6 dB | 0 dB |
| コンプレッション | 0〜1 | 0 |
| ステレオ幅 | 0〜2 | 1 |
| リバーブ量 | 0〜0.5 | 0 |
| リバーブ減衰 | 0〜0.9 | 0.5 |
| リバーブ高域減衰 | 0〜1 | 0.5 |
| ピッチ半音 | −24〜+24 | 0 |
| ピッチミックス | 0〜1 | 0 |
| プレゼンス量 | 0〜1 | 0 |
| プレゼンスドライブ | 0〜8 | 2 |
| プレゼンス周波数 | 500〜8000 Hz | 3200 Hz |

ピッチシフトは曲のテンポと長さを保ったまま音程を変え、ミックス 0 では無効になります。プレゼンスは選んだ周波数帯の成分から非線形の倍音を生成するもので、量 0 では無効になり、イコライザとは別の効果です。既定値のピッチミックス 0 とプレゼンス量 0 では BGM は変わりません。

ワークレットを起動できなかった場合は、無音にせず、エフェクトを通さない経路で再生を続けます。パネルには警告が出て、MCP の `status` では `dspDegraded: true` になります。

## 複数レンダラと録画

再生の時計を持つのはサーバです。ステージ、パネルのプレビュー、OBS のブラウザソースは、各自が先頭から別々に流すのではなく、同じトラックの同じ位置へ参加します。あとから接続したレンダラにも、その時点の選択、位置、設定が渡されます。

そのページが音を出すかどうかは、URL だけで決まります。`?mute=1` は声と BGM をまとめてミュートし、レンダラ別のミュートコマンドはありません。そのためパネルのプレビューは、再生位置には追従しても無音です。

声とエフェクト処理後の BGM は、ビューアの共通出力で合流します。ミュートされていないレンダラが録画すると、そのページで聞こえた音量のまま両方が入ります。
