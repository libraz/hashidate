# コマンド

どのコマンドも `POST /api/command` へ送ります。1 つずつでも、`batch` に並べてまとめてでも構いません。ターミナルからは `yarn ctl <command>` が同じことをします。

| コマンド | 何をするか |
|---|---|
| `perform` | 表情とモーションをひと組にした名前。id なしで、出ているものを解除します。`side` でモーションの使う手を指定します。 |
| `say` | 発話を積みます。`perform` を添えるか、部品を個別に指定するか、テキストの中にキューを書きます。従来の `[performanceId]` 省略記法と、型付きの `[@perform]`・`[@expression]`・`[@gesture]`・`[@hop]`・`[@camera]`・`[@slide]`・`[@bgm]` が使えます。`hold` を付けると台詞が終わっても表情が残ります。表記から読みが決まらない場合は `reading` に仮名で渡します（こちらに演出は書けません）。`side` で手を、`stage` でショットを指定します。 |
| `emotion` | 持続する気分。択一ではなくブレンドです。 |
| `expression` | アバター自身の描き起こし表情。`null` で感情ベクトルに顔を返します。 |
| `overlay` | 描き起こしの効果を、重みを付けて。出ている顔の上に重なるので、複数を同時に上げられます。 |
| `gesture` | ジェスチャ表から 1 つ。id なしで止まります。`side` で手を指定します。 |
| `hop` | 跳躍。骨格全体を平行移動させるためジェスチャとは別のコマンドで、腕が何をしていようと並行して走ります。 |
| `point` | 指先を方位に向けます。ワイヤ上は度で、5 本のどの指でも指せます。解除するまで保持されます。 |
| `look` | 視線がカメラを追う度合い。0 から 1。 |
| `idle` | 自動モードの入切。 |
| `camera` | カメラの立ち位置。画角（`face` / `bust` / `upper` / `full`）と、そこからのずれをヨー・ピッチ・ズームで。ずれは画角に対する相対値なのでアバターを替えても生き残りますし、全フィールドが省略可能です。画角を指定しても、意図的に傾けたカメラが勝手に水平へ戻ることはありません。 |
| `room` | 声が聞こえる空間。id なしで残響なし。カメラと同じく持続します。 |
| `backdrop` | キャラクターが見えている部屋。id なしで素の背景。`room` とは別の軸で、マイクが動いたように聞こえさせずに背景だけ切り替えられます。 |
| `deck` | 見ながら喋るスライドを、ファイル名で。id なしで下ろします。背景と同じ場所を占めるので、出ている間は部屋をしまい、下ろすと元に戻します。 |
| `slide` | ページをめくります。`page` が絶対、`by` が相対で、引数なしは次のページ。端を越えた分は拒否ではなく丸めます。 |
| `place` | 出力フレームの中で、キャラクターがどこに立ち、スライドがその後ろのどこに置かれるか。それぞれ画面の矩形として。カメラではありません。ショットはそのままで、その絵を動かすので、ジェスチャは作ったとおりに再生されます。 `stage.place` として行にも載ります。台本が資料のためにキャラクターを退かせて戻すのはこちらです。 |
| `wear` | スロットに 1 着、またはプリセットで一式。 |
| `avatar` | 別のキャラクターを読み込みます。他のすべてのコマンドが話しかける相手（セッション）ごと差し替える唯一のコマンドなので、レンダラは、モデルが立つまで後続を保持します。着替えまで 1 つの batch で送っても、書いたとおりに動きます。 |
| `tune` | 一度決めたら動かさない層。呼吸、揺れ、跳躍、尻尾、陰影。全フィールドが省略可能で、走っている値にマージするので、フェーダー 1 本が小さなメッセージ 1 通で済みます。`point` と違って範囲は制限します。 |
| `voice` | 声の処理チェインを常設します。`preset` で基準プリセットを選び、`null` で処理を迂回します。`dsp` では `inputGainDb`・`outputGainDb`・`wetMix` と、`retune`・`formant`・`eq`・`gate`・`compressor`・`deesser`・`reverb`・`limiter` の各グループを任意に上書きします。`yarn ctl voice` はプリセット名 1 つか `--bypass` を受け付け、細かな DSP フィールドは API から送ります。 |
| `debug` | 計測の表示を、接続中のすべてのレンダラに。常設に見えて意図的に保存しない唯一の設定です。 |
| `record` | 合成された画のファイルへの書き出しを始める/止める。サイズはコマンドが指定します。実行するのはミュートされていないレンダラだけです。 |
| `bgm` | 設定済みの BGM ライブラリから MP3/FLAC を選択・再生・一時停止・停止し、音量、ループ、フェード（各 0〜10 秒）、BGM 専用の libsonare エフェクトを個別に変更します。別トラックへの切り替えでは前の曲をフェードアウトし、新しい曲をフェードインします。最初の再生と停止中からの再生はフェードインだけで、一時停止・再開・停止は即時です。再生位置はサーバが複数レンダラの間で同期します。再生操作は、行の `[@bgm ...]` キューからも実行できます。キューは現在のフェード設定を使います。 |
| `pause` | キューをその場で止める、または再び動かす。放送中の行は言い切り、何も捨てません。ターンの並びに対してできる 3 番目のことで、並びを保つ唯一のものです。 |
| `interrupt` / `clear` / `reset` | 台詞を切って積んだ分も捨てる / 積んだ分だけ捨てて今の台詞は言い切る / すべて初期状態へ。 |

## `ctl` が足しているもの

`yarn ctl` は上の表への薄いクライアントなので、`yarn ctl camera bust` は `camera` コマンドそのものです。ただし 8 つの動詞だけはコマンドではありません。API を読むだけのものと、どのレンダラにも伝える必要がなくターミナル側で完結するものです。

| `yarn ctl …` | 何か |
|---|---|
| `vocab` | `GET /api/vocabulary`。このアバターに何を頼めるか。システムプロンプトに貼るのはこのオブジェクトです |
| `state` | `GET /api/state` のスナップショットを表示します。レンダラが 1 つも繋がっていなければ、そう表示します |
| `watch` | イベントを Ctrl-C まで追い続けます。発話が実際どういう順で起きているかを確認できます |
| `decks` | ディスク上のスライドと、そのページ数。[スライド](slides.md)を参照してください |
| `motions` | `show/motions/` のジェスチャ。読めなかったファイルとその理由も並びます。[モーション](motions.md)を参照してください |
| `play` | 台本を流します。`--check` ならサーバなしで検証だけ行います。[台本](scripts.md)を参照してください |
| `hold` / `resume` | `pause` コマンドを 2 つに書き分けたものです。[録画](recording.md)を参照してください |

引数なしで `yarn ctl` を実行すると、一覧と実例がまとめて出ます。

## 行の中の型付きキュー

`text` フィールドには次のインライン形式を書けます。`[performanceId]` は `[@perform performanceId]` の省略記法として残っています。

| 形式 | 動作 |
|---|---|
| `[@perform id]` / `[@expression id]` / `[@gesture id]` / `[@hop id]` | 名前付きのプリセット、表情、ジェスチャ、跳躍を変更します。 |
| `[@camera face\|bust\|upper\|full]` | その位置でカメラの画角を変えます。 |
| `[@slide 3]` | 1 始まりの絶対ページへ移動します。 |
| `[@bgm play]` | 選択中の BGM を、一時停止中なら即時に、停止中ならフェードインして再開します。 |
| `[@bgm play track filename]` | 末尾全体をファイル名として選択・再生します。空白と日本語を含められます。 |
| `[@bgm pause]` / `[@bgm stop]` | 選択中のトラックを一時停止または停止します。 |

型付きキューは通常の `say`、`queue`、台本のテキストを通ります。`perform`、`expression`、`gesture`、`hop` では、種別より後ろの全体が id なので、空白と日本語を使えます。角括弧の `[` と `]` は予約文字で、読み上げられません。`room`、`backdrop`、`deck`、`place` は行頭の `stage` 設定に残ります。BGM の音量、ループ、フェード、DSP はパネルまたは `bgm` コマンドのミキサー設定で操作します。相対ページはインラインキューに含まれません。

## どちらの手か

片手のジェスチャは、再生のたびにどちらの腕を使うか引き直されます。表は 1 つのポーズを書いて空いているほうの手に鏡映しており、どのエントリも両手で確認済みなのでそうできます。引き直しているのは、毎回同じ腕で手を振る人物が、人ではなく機構に見えるためです。

`side` に `L` か `R` を渡すと、手を固定できます。資料と反対側の手、あるいは 1 行前と同じ手を使いたい場合に指定します。

```
yarn ctl gesture peace --side L
yarn ctl perform nice --side R
yarn ctl say "こっちだよ" --gesture pointUp --side L
```

フィールドごとではなく 1 行に 1 つなのは、1 ターンが動かすモーションが `gesture` のものか `perform` が名指したものかの 1 つだけで、手を二度書けば食い違う余地しか生まないためです。両手のジェスチャには選ぶ手が無いので、代わりに首の向きが固定されます。[ファイルから読み込んだモーション](motions.md)は自分で `L` か `R` を書いているので、これを無視します。

インラインキューはこれを運びません。文中の `[@gesture peace]` は従来どおり手を引き直すので、手を決めたい行はモーションを行の側に書きます。

## 語彙に含まれないもの

モデル名も提供元もプロンプトも指定するコマンドはありませんし、今後も足しません。何を話すかは境界の向こう側で決まることで、この表はどう話すかだけを扱います。

`voice` と `tune` が MCP 側に無いのは別の理由によります。声をどう混ぜるか、調律の層をどこに置くかは、実際の音と実際の描画を前にして耳と目で判断するもので、送った結果を聞くことも見ることもできない呼び出し側が決めるものではないためです。
