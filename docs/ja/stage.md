# ステージ

キャラクターが**見えている**部屋です。声が聞こえる部屋とは別の軸で、意図的に連動させていません。

## 背景

`dusk` / `night` / `morning` / `rain` の 4 つですが、4 つの部屋ではなく 1 つの部屋を 4 通りに照らしたものです。躯体も窓も家具の大半も共有していて、違うのは光がどこから来るか、その色温度、そして画面のどこに最も明るい値と最も暗い値が落ちるかだけです。背景は顔の後ろで 2 時間もたなければならないので、配色ではなく明度の構造で組んでいます。

モデルファイルは使っていません。形状はコードで書き、表面——漆喰、フローリング、織りの布、窓の外——は起動時に canvas へ生成します。ライセンスするものも再配布するものもなく、壁のムラが差分でレビューできます。

指定は URL です。OBS のブラウザソースに渡すのはこのアドレスそのものです。

```
http://127.0.0.1:8765/?size=1920x1080&backdrop=night
```

知らない名前はエラーではなく素の背景になります。URL はエラーの報告先がないフィールドに打ち込まれるものだからです。配信の途中で変えるためのコマンドでもあります。

```sh
yarn ctl backdrop dusk
yarn ctl backdrop        # 素の背景
```

## ゲーム画面の上に重ねる

背景を選ばないと、キャラクターは単色の上に立ちます。これは意匠ではなく最低水準です。ブラウザで開いただけのページは、後ろに何か塗らなければ市松模様になります。ただ、ゲームのキャプチャの上ではその単色のほうが邪魔になります。配信の主題を覆う不透明な矩形だからです。

`?transparent=1` でそれを外します。あとの合成は OBS の仕事です。

```
http://127.0.0.1:8765/?transparent=1&place=bottom-right:0.32x0.6
```

下にゲームキャプチャかウィンドウキャプチャ、上にこの URL のブラウザソース。それでキャラクターがその上に乗ります。`place` の挙動はスライドの前に立たせるときと同じで、ショットは動かさず、その絵を小さくするだけです。空いた側はフレームの外へ出して切り落とします。

背景を選べばそちらが勝ちます。部屋は自前の背景を持つ不透明な形状で、これを入れたまま部屋を選ぶのは「部屋を出せ」という指示だからです。

URL に置いていて、意図的にコマンドにしていません。下に何があるかはソースを置いた OBS のシーンの性質で、台本の 1 行に知りようがないからです。ゲーム画面をこのページの**中に**取り込む案もありましたが、肝心の場所で動きません。OBS に埋め込まれたブラウザには画面キャプチャの許可を出す方法がなく、素のブラウザウィンドウでしか動かないうえ、ゲームの全フレームを 2 度取ることになります。

## フレームのどこに立たせるか

```sh
yarn ctl place avatar --anchor bottom-right --width 0.32 --height 0.6
```

小さくなるのは**絵**であって、ショットではありません。カメラは動かないので、画角に合わせて作ったジェスチャはそのまま同じように再生されます。

矩形は**場所**であって、ショットを決めるものではありません。ここは意図的にそうしてあります。画角はワールド空間の上端と下端で定義してあるので、別の形の矩形に向けると必ず何かを捨てることになり、そして思いつく 2 つの答えはどちらも誤りです。

- 矩形を埋めれば上下は保たれて、腕が両側から切り落とされます。上げた手も髪の大半もそこにあります。
- 横が収まるまでカメラを引けば何も切れませんが、上下も同じ倍率で広がるので、上半身のショットが黙って全身になります。

そこで描くのは画面そのものの形です。それを場所の中に収まる大きさへ縮めます。画面いっぱいなら映っていたはずの絵が、小さく、端に寄って出ます。場所のうち絵が覆わない部分は透明なので、そこには後ろのスライドが見えます。

そして端に着くのは、その絵ではなく**キャラクター自身**です。画角は横に広い絵で、その真ん中に細い人が立っているので、絵の端を画面の端に合わせるとキャラクターは端から画面 1/4 ほど手前で止まり、広い空白の前に立つことになります。空いている側は端の外へ押し出して、そこで切ります。

つまりキャラクターについては、2 つの比のうち小さいほうしか効きません。1 のままなら寄せ先がありません。2 つの比が本当に要るのはスライドのほうで、あちらには `fit` があります。[スライド](slides.md)を参照してください。
