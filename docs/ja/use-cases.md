# 使いどころ

このランタイムが使われる 8 つの形です。どれも同じランタイムで、前に置く呼び出し側が違うだけです。

| # | 形 | 動かすのは誰か |
|---|---|---|
| [1](#1-コメントに答える-aituber) | コメントに答える AITuber | LLM のループ（HTTP か MCP） |
| [2](#2-ゲーム画面の上での実況) | ゲーム画面の上での実況 | 何でも。合成は OBS |
| [3](#3-スライドを使った説明) | スライドを使った説明 | 台本、またはスライドを読んだモデル |
| [4](#4-モデルを使わない台本どおりの進行) | モデルを使わない、台本どおりの進行 | シェルスクリプト |
| [5](#5-一本撮って動画にする) | 一本撮って動画にする | パネルの前のオペレータ |
| [6](#6-区間に-bgm-を添える) | 区間に BGM を添える | BGM タブ、または `bgm` ツール |

| [8](#8-組んだばかりのモデルの確認) | 組んだばかりのモデルの確認 | ターミナルの前のオペレータ |

## 1. コメントに答える AITuber

一番多い使い方で、境界をここに引いた理由でもあります。コメントを読み、モデルに何を言うか聞き、返ってきた答えを渡すところまでが呼び出し側の仕事です。その先は hashidate が担当します。

```sh
yarn ctl say "こんばんは。今日は雑談です。" --perform hello --wait
```

プログラムから見れば `POST /api/command` が 1 回、MCP クライアントからなら `speak` ツールが 1 回です。そのアバターが実際に持つ id はツールのスキーマに入っているので、モデルは一覧から選ぶだけで、id を捏造しません。[MCP アダプタ](mcp.md)を参照してください。

答えは 1 行ずつではなく、まとめて送ってください。行間の無音が 1.2 秒から 0.3 秒になります。[まとめて送る](control-api.md#まとめて送る)を参照してください。

## 2. ゲーム画面の上での実況

背景を透過させてキャラクターだけをゲームキャプチャの上に立たせ、合成は OBS に任せます。

```
http://127.0.0.1:8765/?transparent=1&place=bottom-right:0.32x0.6
```

下にゲームキャプチャかウィンドウキャプチャ、上にこの URL のブラウザソースを置きます。ショットは動かず、その絵が小さくなるだけなので、ジェスチャは作ったとおりに再生されます。[ステージ](stage.md#ゲーム画面の上に重ねる)を参照してください。

## 3. スライドを使った説明

PDF を後ろに出して、それを見ながら喋らせます。ページ送りは行に載せられるので、スライドはオペレータではなく台本に追従します。

```sh
yarn ctl deck intro
yarn ctl say "まず全体像から。" --slide 2
yarn ctl place avatar --anchor bottom-right --width 0.32 --height 0.6
```

スライドはテキストとしても読めます。この機能の目的はそこにあり、スライドを読めるモデルは、そのスライドについての台本を書けて、各行にページ番号を振れます。[スライド](slides.md)を参照してください。

## 4. モデルを使わない、台本どおりの進行

言語モデルは必須ではありません。シェルスクリプトでもオーケストレータとして十分ですし、区間のリハーサルや不具合の再現には一番速い方法です。

```sh
yarn ctl backdrop night
yarn ctl say "[hello]こんばんは。[explain]今日はこの話をします。" --camera bust --wait
yarn ctl perform sleepy
```

## 5. 一本撮って動画にする

台本どおりの進行の、もう一つの形です。配信ではなく、一度だけ録ります。パネルのキュータブの先頭に `show/scripts/` の中身が並び、押すと**再生せずに**読み込みます。行はその下に出て、音声合成が進んでいるキューを抱えたまま画角を決められます。録画タブで録画を押すとそこで初めて解放されるので、ファイルは合成待ちからではなく一行目の出だしから始まります。

最終行の少しあとで自動的に止まり、mp4 が `show/recordings/` に落ちます。書き出すのはミュートされていないほうのレンダラで、ふつうの机の上ではパネルのプレビューではなくステージです。

```sh
yarn ctl play opening --hold   # 同じ一時停止をコマンドラインから
yarn ctl resume
```

[録画](recording.md)を参照してください。

## 6. 区間に BGM を添える

MP3 または FLAC を `show/bgm/` の直下に置き、BGM タブから選びます。MCP の呼び出し側なら、`bgm` の list が返した正確な id を選択します。音量、ループ、libsonare エフェクトは声とは独立しており、同じミックスがステージ、OBS、ローカル録画へ届きます。

```sh
yarn ctl bgm list
yarn ctl bgm play opening.mp3 --volume 0.16 --loop on
```

[BGM](bgm.md)を参照してください。

## 7. 手で配信を回す

`/panel/` のパネルは配信を回すための操作面です。台本とその履歴、演技、音声、BGM、衣装、調律、計測が並び、プレビューの下にアバター・画角・背景・アイドルの切替があります。パネルの操作はすべて制御 API を通るので、オペレータにできることはオーケストレータにもできます。[操作面](surfaces.md)を参照してください。

## 8. 組んだばかりのモデルの確認

そのアバターに何を頼めるかは、モデル自身のシェイプとメッシュから発見します。つまり vocabulary はモデルについての報告書です。

```sh
yarn ctl avatar manuka
yarn ctl vocab
yarn ctl point 40 25 --extent 0.9 --finger little
yarn ctl watch
```

状態に載る `strain` は、直前の指先解決が各腕にどれだけ無理をさせたかを表します。狙いどおりに届いたのか、近似しかできなかったのかは、これで見分けます。[制御 API](control-api.md#返ってくるもの)を参照してください。

## 向いていないこと

- AI コンパニオンとして完結させること。ここには記憶も人格も会話もありません。
- クラウドサービスにすること。すべて `127.0.0.1` に bind しますし、それを変えるフラグはありません。
- リギングや衣装の作成。それは Blender の仕事で、`tools/blender` が境目です。
